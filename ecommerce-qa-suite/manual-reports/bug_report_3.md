# Bug Report: Search results page crashes on empty query

**Steps to Reproduce:**
1. Navigate to the search page.
2. Click the "Search" button without entering a query.

**Severity:** Low

**Expected Result:**
The page should display a message like "Please enter a search query."

**Actual Result:**
The page crashes with a 500 Internal Server Error.
