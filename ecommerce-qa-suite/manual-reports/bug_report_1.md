# Bug Report: Login button not responsive on mobile

**Steps to Reproduce:**
1. Open the website on a mobile device (e.g., iPhone 12).
2. Navigate to the login page.
3. Enter valid credentials.
4. Tap the "Login" button.

**Severity:** High

**Expected Result:**
The user should be logged in and redirected to the dashboard.

**Actual Result:**
The "Login" button does not respond to taps. Nothing happens.
